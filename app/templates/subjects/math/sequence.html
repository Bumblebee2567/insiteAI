Sequences and Series

Learn how numbers can follow patterns, how sequences are formed, how arithmetic and geometric progressions work, and how series are used to find the sum of terms.

1. What is a Sequence?

A sequence is an ordered list of numbers that follows a particular rule or pattern.

2, 4, 6, 8, 10, ...

The numbers in a sequence are called its terms.

A sequence may continue forever or may contain a fixed number of terms.

Examples of Sequences

3, 6, 9, 12, 15, ...

1, 4, 9, 16, 25, ...

2, 6, 18, 54, 162, ...

The first sequence increases by 3 each time. The second consists of square numbers. The third is multiplied by 3 each time.

2. Terms and Sequence Notation

The position of a term in a sequence is important. We usually use n to represent the position.

a₁ = first term
a₂ = second term
a₃ = third term
aₙ = nth term

The symbol aₙ means "the term at position n".

Example

Sequence:
5, 8, 11, 14, 17, ...

Therefore:

a₁ = 5
a₂ = 8
a₃ = 11
a₄ = 14

3. Finding the Nth Term

The nth term is a formula that allows us to calculate any term in a sequence without writing out all the previous terms.

For example, instead of listing the first 100 terms, a formula can give us the 100th term directly.

Example

Sequence:
4, 7, 10, 13, 16, ...

The difference is 3.

Since this is arithmetic:

aₙ = a₁ + (n - 1)d

Therefore:

aₙ = 4 + 3(n - 1)
aₙ = 3n + 1

Finding a Specific Term

Find the 20th term.
a₂₀ = 3(20) + 1
= 61

4. Arithmetic Sequence

An arithmetic sequence is a sequence in which the difference between consecutive terms is constant.

This constant difference is called the common difference, represented by d.

d = a₂ - a₁
d = a₃ - a₂
d = a₄ - a₃

Example

7, 11, 15, 19, 23, ...

Each term increases by 4.

d = 4

Arithmetic Sequences Can Decrease

30, 25, 20, 15, 10, ...
d = -5

5. Nth Term of an Arithmetic Progression

The nth-term formula for an arithmetic progression is:

aₙ = a + (n - 1)d

where:

  • a = first term
  • n = position of the required term
  • d = common difference
  • aₙ = nth term

Example

Find the 15th term of:
6, 10, 14, 18, ...

First term:

a = 6

Common difference:

d = 4

Therefore:

a₁₅ = 6 + (15 - 1)(4)
= 6 + 56
= 62

Finding the Position of a Term

Which term of 5, 9, 13, 17, ... is 81?
81 = 5 + (n - 1)4
81 = 5 + 4n - 4
81 = 4n + 1
80 = 4n
n = 20

Therefore, 81 is the 20th term.

6. Arithmetic Series and Sum of an AP

When the terms of a sequence are added together, the resulting expression is called a series.

3 + 6 + 9 + 12 + 15 + ...

If the sequence is arithmetic, the resulting series is an arithmetic series.

Sum of the First n Terms

Sₙ = n/2 [2a + (n - 1)d]

Another useful form is:

Sₙ = n/2 (a + l)

where l is the last term.

Example

Find the sum of the first 20 terms:
2 + 5 + 8 + 11 + ...

Here:

a = 2
d = 3
n = 20

Use:

Sₙ = n/2 [2a + (n - 1)d]
S₂₀ = 20/2 [2(2) + 19(3)]
= 10[4 + 57]
= 10(61)
= 610

Sum Using the Last Term

Sₙ = n/2(a + l)
Example:

Find the sum:

4 + 8 + 12 + ... + 100

First find the number of terms:

100 = 4 + (n - 1)4
100 = 4n
n = 25

Then:

S₂₅ = 25/2(4 + 100)
= 25/2 × 104
= 1300

7. Arithmetic Progression Word Problems

Arithmetic progressions are commonly used in situations where a quantity increases or decreases by the same amount each time.

Word Problem:

A student saves ₦500 in the first week and increases the amount saved by ₦200 every week. How much will the student save in the 12th week?

This is an arithmetic progression because the weekly increase is constant.

a = 500
d = 200
n = 12
a₁₂ = 500 + (12 - 1)(200)
= 500 + 2200
= ₦2700

Therefore, the student saves ₦2,700 in the 12th week.

Word Problem:

A theatre has 20 seats in the first row. Each successive row has 3 more seats than the previous row. How many seats are in the 15th row?

a = 20
d = 3
n = 15
a₁₅ = 20 + (15 - 1)(3)
= 62

The 15th row contains 62 seats.

8. Geometric Sequence

A geometric sequence is a sequence in which each term is obtained by multiplying the previous term by the same constant number.

This constant number is called the common ratio, represented by r.

r = a₂/a₁

Example

3, 6, 12, 24, 48, ...
r = 2

Geometric Sequence with Fractions

81, 27, 9, 3, 1, ...
r = 1/3

Negative Common Ratio

2, -6, 18, -54, 162, ...
r = -3

A negative ratio causes the signs of the terms to alternate.

9. Nth Term of a Geometric Progression

The nth term of a geometric progression is:

aₙ = arⁿ⁻¹

where:

  • a = first term
  • r = common ratio
  • n = term position
  • aₙ = nth term

Example

Find the 8th term of:
2, 6, 18, 54, ...
a = 2
r = 3
n = 8
a₈ = 2(3)⁷
= 2(2187)
= 4374

Finding the Common Ratio

Example:
5, 15, 45, 135, ...
r = 15/5
r = 3

10. Geometric Series

A geometric series is formed when the terms of a geometric sequence are added.

a + ar + ar² + ar³ + ...

Sum of the First n Terms

Sₙ = a(rⁿ - 1)/(r - 1)

An equivalent form is:

Sₙ = a(1 - rⁿ)/(1 - r)

Both formulas give the same result. Choose the form that makes the calculation easier.

Example

Find the sum of the first 6 terms:
2 + 6 + 18 + 54 + ...
a = 2
r = 3
n = 6
S₆ = 2(3⁶ - 1)/(3 - 1)
= 2(729 - 1)/2
= 728

11. Geometric Progression Word Problems

Geometric progressions are useful when a quantity changes by a constant percentage or multiplier.

Word Problem:

A bacteria culture contains 500 bacteria initially. The population triples every hour. How many bacteria will there be after 6 hours?

a = 500
r = 3
n = 7

The initial population represents the first term, so after 6 growth periods we use the seventh term.

a₇ = 500(3)⁶
= 500(729)
= 364,500
Word Problem:

A machine loses 10% of its value every year. If it is initially worth ₦2,000,000, what will its value be after 4 years?

Losing 10% means 90% remains each year.

r = 0.90
Value = 2,000,000(0.9)⁴
≈ ₦1,312,200

12. Sequences vs Series

A sequence is a list of terms, while a series is the sum of those terms.

Sequence

2, 4, 6, 8, 10, ...

Series

2 + 4 + 6 + 8 + 10 + ...

This distinction is important because sequence questions usually ask about individual terms, while series questions often ask for totals.

Sigma Notation

Large sums can be written using the Greek letter sigma, Σ.

Σ aₙ

Sigma notation provides a compact way to represent the addition of many terms.

Example:
Σ from n=1 to 5 of n
= 1 + 2 + 3 + 4 + 5
= 15

13. Infinite Sequences and Infinite Series

An infinite sequence continues indefinitely.

1, 1/2, 1/3, 1/4, 1/5, ...

An infinite series is an infinite sum.

1 + 1/2 + 1/3 + 1/4 + ...

Infinite Geometric Series

An infinite geometric series has a finite sum only when the absolute value of the common ratio is less than 1.

|r| < 1

When this condition is satisfied:

S∞ = a/(1-r)

Example

Find the sum:
8 + 4 + 2 + 1 + ...
a = 8
r = 1/2

Since:

|1/2| < 1

The series converges.

S∞ = 8/(1 - 1/2)
= 8/(1/2)
= 16

When the Ratio Is Not Less Than 1 in Magnitude

If |r| is greater than or equal to 1, the infinite geometric series does not have a finite sum.

|r| ≥ 1 → divergent

14. Mixed Sequence and Series Problems

Examination questions often combine several ideas. You may need to identify whether a sequence is arithmetic or geometric, find an unknown term, determine the number of terms and then calculate a sum.

Word Problem:

The first term of an arithmetic progression is 7 and the common difference is 5. Find the 25th term and the sum of the first 25 terms.

First find the 25th term.

a₂₅ = 7 + (25 - 1)(5)
= 127

Now use the sum formula.

S₂₅ = 25/2(7 + 127)
= 25/2 × 134
= 1675
Word Problem:

An amount of ₦10,000 is invested at a growth factor of 1.08 each year. Find the amount after 5 years.

This is geometric growth.

A = 10,000(1.08)⁵
A ≈ ₦14,693.28
