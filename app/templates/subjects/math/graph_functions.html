Coordinate Geometry

Understanding points and positions on a graph.

The Cartesian Plane

A Cartesian plane is formed by two perpendicular number lines: the horizontal x-axis and the vertical y-axis.

  • x-axis — horizontal axis
  • y-axis — vertical axis
  • origin — point (0, 0)
  • coordinates are written as (x, y)

Quadrants

  • Quadrant I: (+, +)
  • Quadrant II: (-, +)
  • Quadrant III: (-, -)
  • Quadrant IV: (+, -)

Distance Between Two Points

d = √[(x₂ − x₁)² + (y₂ − y₁)²]

Midpoint

M = ((x₁ + x₂)/2, (y₁ + y₂)/2)
Example:

Find the midpoint of A(2, 4) and B(8, 10).

M = ((2 + 8)/2, (4 + 10)/2)

M = (5, 7)

Straight-Line Graphs

Equations and properties of straight lines.

General Form

y = mx + c

Here, m represents the gradient and c represents the y-intercept.

Examples of Straight Lines

  • y = 2x + 3
  • y = -x + 5
  • y = 4x
  • y = 7

Intercepts

The y-intercept is where a line crosses the y-axis. The x-intercept is where it crosses the x-axis.

Gradient and Slope

Measuring how steep a line is.

Gradient Formula

m = (y₂ − y₁) / (x₂ − x₁)

Types of Gradient

  • Positive gradient — line rises from left to right.
  • Negative gradient — line falls from left to right.
  • Zero gradient — horizontal line.
  • Undefined gradient — vertical line.

Parallel Lines

Parallel straight lines have equal gradients.

m₁ = m₂

Perpendicular Lines

For two non-vertical perpendicular lines, their gradients have a product of -1.

m₁ × m₂ = -1

Plotting and Interpreting Graphs

Turning data and equations into graphs.

Plotting Points

A point is plotted using its x-coordinate first and its y-coordinate second.

(x, y)

Tables of Values

A table can be used to calculate corresponding x and y values before plotting them on a graph.

Reading Graphs

  • Read coordinates.
  • Identify maximum and minimum values.
  • Find intercepts.
  • Compare increasing and decreasing regions.
  • Interpret real-world information.

Distance-Time Graphs

The gradient of a distance-time graph represents speed.

Velocity-Time Graphs

The gradient represents acceleration, while the area under the graph can represent displacement.

Functions

Understanding mathematical input-output relationships.

What Is a Function?

A function is a rule that assigns exactly one output to each allowed input.

f(x) = y

Function Notation

If

f(x) = 2x + 3

then:

f(4) = 2(4) + 3 = 11

Domain

The domain is the set of possible input values.

Range

The range is the set of possible output values.

One-to-One Functions

A one-to-one function gives different outputs for different inputs.

Quadratic Graphs

Parabolas, roots and turning points.

Quadratic Function

y = ax² + bx + c

Shape of a Parabola

When a is positive, the parabola opens upward. When a is negative, it opens downward.

Roots

The roots are the x-values where the graph crosses or touches the x-axis.

Quadratic Formula

x = [-b ± √(b² − 4ac)] / 2a

Discriminant

Δ = b² − 4ac
  • Δ > 0 — two real roots
  • Δ = 0 — one repeated real root
  • Δ < 0 — no real roots

Graphs and Simultaneous Equations

Finding solutions using intersections.

Two Straight Lines

When two straight-line graphs intersect, the coordinates of their intersection give the solution to the simultaneous equations.

Example:

y = 2x + 1

y = -x + 7

Their intersection gives the common solution for x and y.

Line and Curve

A straight line can also intersect a quadratic curve. The intersection points represent the simultaneous solutions.

Variation

How one quantity changes with another.

Direct Variation

y ∝ x

This means y is directly proportional to x.

y = kx

Inverse Variation

y ∝ 1/x
y = k/x

Power Variation

y ∝ xⁿ

Variation is widely used in physics, economics, engineering and science.

Graph Transformations

Moving and changing the shape of graphs.

Translation

A graph can be shifted horizontally or vertically.

Reflection

Graphs can be reflected across the x-axis or y-axis.

Stretching and Compression

Multiplying a function by a constant can change its vertical scale.

y = af(x)

Changing the input can affect the horizontal scale.

y = f(bx)
