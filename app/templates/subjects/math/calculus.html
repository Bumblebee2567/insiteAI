Calculus

1. Introduction to Calculus

Calculus is the branch of mathematics used to study change and accumulation.

It is divided mainly into two connected areas:

  • Differentiation — studies rates of change and slopes.
  • Integration — studies accumulation, total change and areas.

A Simple Idea

If the position of a car changes with time, calculus can help determine its instantaneous velocity.

Velocity = rate of change of position

Similarly, if velocity is known, integration can be used to determine displacement.

2. Limits

A limit describes the value that a function approaches as its input approaches a particular value.

lim x→a f(x)

The idea of a limit is important because the derivative is built from a limiting process.

Example

Consider:
f(x) = x²

As x approaches 2:

lim x→2 x² = 4

3. Differentiation from First Principles

First principles gives the fundamental definition of the derivative.

f'(x) = lim h→0 [f(x+h) - f(x)] / h

The expression represents the slope of a secant line as two points on a curve move closer together.

When the distance between the points approaches zero, the secant slope approaches the tangent slope.

Example

Find the derivative of:
f(x) = x²

First:

f(x+h) = (x+h)²
= x² + 2xh + h²

Substitute into the definition:

f'(x) = lim h→0 [(x² + 2xh + h²) - x²] / h
= lim h→0 [2xh + h²] / h
= lim h→0 (2x + h)
= 2x

Therefore:

f'(x) = 2x

4. Derivatives and du/dx

A derivative measures the instantaneous rate of change of one quantity with respect to another.

If y depends on x, we commonly write:

dy/dx

The notation means "the rate at which y changes with respect to x."

Power Rule

d/dx (xⁿ) = nxⁿ⁻¹

Example

Differentiate:
y = x⁵
dy/dx = 5x⁴

Constants

d/dx(c) = 0

A constant does not change, so its derivative is zero.

Constant Multiplication

d/dx [c f(x)] = c f'(x)

Sum and Difference

d/dx [f(x) ± g(x)] = f'(x) ± g'(x)

5. Basic Differentiation Rules

Polynomial Example

Differentiate:
y = 4x⁵ - 3x³ + 7x - 9
dy/dx = 20x⁴ - 9x² + 7

Exponential Function

d/dx(eˣ) = eˣ

General Exponential

d/dx(aˣ) = aˣ ln(a)

Logarithm

d/dx(ln x) = 1/x

Trigonometric Functions

d/dx(sin x) = cos x
d/dx(cos x) = -sin x
d/dx(tan x) = sec²x

6. Product Rule

When two functions are multiplied together, we use the product rule.

d/dx(uv) = u(dv/dx) + v(du/dx)

In short:

(uv)' = u'v + uv'

Example

Differentiate:
y = x² sin x

Let:

u = x²
v = sin x
u' = 2x
v' = cos x

Therefore:

y' = (2x)(sin x) + (x²)(cos x)

7. Quotient Rule

When one function is divided by another, the quotient rule is used.

d/dx(u/v) = [v(du/dx) - u(dv/dx)] / v²

Example

Differentiate:
y = x² / (x + 1)

Let:

u = x²
v = x + 1
u' = 2x
v' = 1
y' = [(x + 1)(2x) - x²(1)] / (x + 1)²
y' = (x² + 2x) / (x + 1)²

8. Chain Rule

The chain rule is used when one function is inside another function.

dy/dx = dy/du × du/dx

This is why the notation du/dx is particularly useful when differentiating composite functions.

Example

Differentiate:
y = (3x² + 2)⁵

Let:

u = 3x² + 2
dy/du = 5u⁴
du/dx = 6x
dy/dx = 5(3x² + 2)⁴(6x)
dy/dx = 30x(3x² + 2)⁴

9. Implicit Differentiation

Sometimes x and y are mixed together in an equation, so y cannot easily be written as a function of x. In such cases, we differentiate implicitly.

Important Rule

d/dx(y) = dy/dx

For powers of y, the chain rule is required.

d/dx(y²) = 2y(dy/dx)

Example

Given:
x² + y² = 25

Differentiate both sides:

2x + 2y(dy/dx) = 0
dy/dx = -x/y

10. Rate of Change

The derivative is fundamentally a rate of change.

Rate of change = dy/dx

If distance changes with time:

ds/dt = velocity

If velocity changes with time:

dv/dt = acceleration

Example

Given:
s(t) = t³ + 2t²

Velocity is the derivative of displacement.

v(t) = ds/dt
= 3t² + 4t

Acceleration is the derivative of velocity.

a(t) = dv/dt
= 6t + 4

11. Increasing and Decreasing Functions

The first derivative can tell us whether a function is increasing or decreasing.

f'(x) > 0 → function is increasing
f'(x) < 0 → function is decreasing

This is because the derivative represents the slope. A positive slope means the graph rises, while a negative slope means the graph falls.

Example

Given:
f(x) = x³ - 3x

Differentiate:

f'(x) = 3x² - 3

Factor:

f'(x) = 3(x - 1)(x + 1)

The critical points are:

x = -1, 1

Testing intervals allows us to determine where the function increases and decreases.

12. Stationary Points and Turning Points

A stationary point occurs where the derivative is zero.

f'(x) = 0

A stationary point may be:

  • A local maximum
  • A local minimum
  • A stationary point of inflection

Example

Find the stationary points of:
f(x) = x² - 4x + 3
f'(x) = 2x - 4

Set the derivative equal to zero:

2x - 4 = 0
x = 2

Find the corresponding y-value:

f(2) = 4 - 8 + 3
= -1

Therefore the stationary point is:

(2, -1)

13. Roots and Intercepts

A root of a function is a value of x for which the function equals zero.

f(x) = 0

Graphically, roots are the points where the graph crosses or touches the x-axis.

Example

Find the roots:
x² - 5x + 6 = 0
(x - 2)(x - 3) = 0
x = 2
x = 3

Roots and Calculus

Roots can also be important when studying the behaviour of a differentiated function.

For example, solving f'(x) = 0 gives stationary points, while solving f(x) = 0 gives x-intercepts.

14. Maximum, Minimum and Optimization

Calculus can be used to find the greatest or smallest possible value of a quantity.

At many local maximum and minimum points:

f'(x) = 0

The second derivative can help determine the nature of the stationary point.

f''(x) > 0 → local minimum

f''(x) < 0 → local maximum

Example

Find the maximum or minimum of:
f(x) = -x² + 6x + 2
f'(x) = -2x + 6

Set the derivative equal to zero:

-2x + 6 = 0
x = 3

Since:

f''(x) = -2

The point is a maximum.

f(3) = -(3²) + 6(3) + 2
= 11

15. Calculus Word Problems

Calculus becomes especially useful when a question describes a real-world quantity changing with time, distance, volume, cost, area or another variable.

Rate-of-Change Problem

Problem:

The distance travelled by a particle is given by:

s(t) = t³ - 6t² + 9t

Find its velocity.

v(t) = ds/dt
v(t) = 3t² - 12t + 9

Therefore, the velocity at any time t can be found by substituting the required value of t.

Optimization Problem

Problem:

A rectangle has perimeter 40 cm. Find the dimensions that give the maximum possible area.

Let the length be x and the width be y.

2x + 2y = 40
y = 20 - x

Area:

A = xy
A = x(20 - x)
A = 20x - x²

Differentiate:

dA/dx = 20 - 2x

At the maximum:

20 - 2x = 0
x = 10
y = 20 - 10
y = 10

Therefore, the maximum-area rectangle is a square measuring 10 cm by 10 cm.

16. Introduction to Integration

Integration is closely related to differentiation. While differentiation measures instantaneous change, integration can be used to find accumulated change.

Integration is also used to find areas under curves.

∫ f(x) dx

Basic Integration Rule

∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C , n ≠ -1

C represents the constant of integration.

Example

Integrate:
∫ x³ dx
= x⁴/4 + C

17. Integration Rules

Constant

∫ c dx = cx + C

Constant Multiple

∫ cf(x) dx = c∫f(x)dx

Sum and Difference

∫[f(x) ± g(x)]dx = ∫f(x)dx ± ∫g(x)dx

Exponential

∫eˣ dx = eˣ + C

Logarithmic Form

∫(1/x)dx = ln|x| + C

Trigonometric Integrals

∫sin x dx = -cos x + C

∫cos x dx = sin x + C

∫sec²x dx = tan x + C

Example

Integrate:
∫(6x² - 4x + 3)dx
= 2x³ - 2x² + 3x + C

18. Definite Integrals

A definite integral has limits and produces a numerical result rather than an arbitrary constant.

∫ₐᵇ f(x) dx

To evaluate it, first find an antiderivative and then substitute the upper and lower limits.

∫ₐᵇ f(x)dx = F(b) - F(a)

Example

Evaluate:
∫₀² x² dx

First integrate:

∫x²dx = x³/3

Apply the limits:

[x³/3]₀²
= 8/3 - 0
= 8/3

19. Area Under a Curve

A definite integral can represent the signed area between a curve and the x-axis.

Area = ∫ₐᵇ f(x) dx

When the function remains above the x-axis, the integral directly gives the geometric area.

Area Between Two Curves

If one curve lies above another, the area between them is found by integrating their difference.

Area = ∫ₐᵇ [upper function - lower function] dx

Example

Find the area under:
y = x²

between x = 0 and x = 2.

Area = ∫₀² x² dx
= 8/3
