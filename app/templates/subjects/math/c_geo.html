1. Introduction to Coordinate Geometry

Coordinate geometry is a part of mathematics where we use numbers and a graph to describe where things are located.

Instead of simply saying that a point is "somewhere to the right and above another point", coordinate geometry allows us to describe its exact position using numbers.

This makes it possible to study shapes, distances, lines, angles and many other geometric ideas using algebra.

Why Do We Need Coordinates?

Imagine that you are trying to tell someone where a particular house is located on a large map. Saying "it is near the middle" would not be very precise.

Coordinates solve this problem. Every position on the coordinate plane can be described using a pair of numbers.

The Basic Idea

A coordinate is normally written as:

(x, y)

The first number tells us how far to move horizontally. The second number tells us how far to move vertically.

Simple Example

Consider the point (4, 3).

Start at the origin.
Move 4 units to the right.
Then move 3 units upward.

You arrive at the point (4, 3).

2. The Coordinate Plane

The coordinate plane is the grid used to locate points. It is made from two number lines that cross each other.

The x-axis

The horizontal line is called the x-axis.

Moving to the right gives positive x-values, while moving to the left gives negative x-values.

The y-axis

The vertical line is called the y-axis.

Moving upward gives positive y-values, while moving downward gives negative y-values.

The Origin

The point where the x-axis and y-axis meet is called the origin.

Origin = (0, 0)

The Four Quadrants

The two axes divide the coordinate plane into four regions called quadrants.

  • Quadrant I: x is positive and y is positive.
  • Quadrant II: x is negative and y is positive.
  • Quadrant III: x is negative and y is negative.
  • Quadrant IV: x is positive and y is negative.
Example

Which quadrant contains the point (-5, 2)?

x = -5 → negative
y = 2 → positive

Therefore, the point is in Quadrant II.

3. Plotting and Reading Points

A point is represented by an ordered pair:

(x, y)

The order matters. The x-coordinate always comes first, followed by the y-coordinate.

How to Plot a Point

  1. Start at the origin.
  2. Read the x-coordinate.
  3. Move horizontally.
  4. Read the y-coordinate.
  5. Move vertically.
  6. Mark the point.
Example

Plot the point (-3, -4).

Start at (0, 0).
Move 3 units left because x = -3.
Move 4 units down because y = -4.

The point lies in Quadrant III.

Points on the Axes

If a point has an x-coordinate of zero, it lies on the y-axis.

(0, y)

If a point has a y-coordinate of zero, it lies on the x-axis.

(x, 0)

4. Distance Between Two Points

Sometimes we know the coordinates of two points and want to know how far apart they are.

If the points lie horizontally or vertically, the distance can be found by simple subtraction.

But if the points are separated both horizontally and vertically, we can use the distance formula.

Distance Formula

d = √[(x₂ - x₁)² + (y₂ - y₁)²]

This formula comes from the Pythagorean theorem. The horizontal difference becomes one side of a right triangle, the vertical difference becomes the other side, and the distance between the points becomes the hypotenuse.

Worked Example

Find the distance between A(2, 3) and B(6, 6).

x₁ = 2, y₁ = 3
x₂ = 6, y₂ = 6

d = √[(6 - 2)² + (6 - 3)²]
d = √[4² + 3²]
d = √[16 + 9]
d = √25
d = 5 units

5. Midpoint of a Line Segment

The midpoint is the point that lies exactly halfway between two endpoints.

Think of a line segment as a ruler. If you cut it exactly in half, the point where you cut it is the midpoint.

Midpoint Formula

M = ((x₁ + x₂)/2, (y₁ + y₂)/2)

Notice what the formula does: it finds the average of the two x-coordinates and separately finds the average of the two y-coordinates.

Worked Example

Find the midpoint of A(2, 4) and B(8, 10).

x-coordinate:
(2 + 8) / 2 = 10 / 2 = 5

y-coordinate:
(4 + 10) / 2 = 14 / 2 = 7

Therefore:
M = (5, 7)

6. Gradient or Slope

The slope tells us how steep a line is and which direction the line is moving.

Imagine walking along a hill. A very steep hill has a large slope, while a flat road has a slope of zero.

Rise and Run

Slope compares the vertical change with the horizontal change.

Slope = rise / run

Slope Formula

m = (y₂ - y₁) / (x₂ - x₁)

Understanding Positive and Negative Slope

A positive slope means the line rises as you move from left to right.

A negative slope means the line falls as you move from left to right.

A slope of zero represents a horizontal line.

A vertical line has an undefined slope because its horizontal change is zero.

Worked Example

Find the slope of the line passing through A(2, 3) and B(6, 11).

m = (11 - 3) / (6 - 2)
m = 8 / 4
m = 2

7. Straight-Line Graphs

A straight-line graph is a graph whose points lie along one straight path.

One of the most common ways to represent a straight line is the slope-intercept form.

y = mx + c

Here, m represents the slope and c represents the y-intercept.

What Is the y-intercept?

The y-intercept is the point where the line crosses the y-axis.

Since every point on the y-axis has x = 0, the y-intercept can be found by putting x = 0.

Example

Consider:

y = 2x + 3
The slope is 2.
The y-intercept is 3.

Therefore, the line crosses the y-axis at:
(0, 3)

Point-Slope Form

If we know a point on a line and its slope, we can use point-slope form.

y - y₁ = m(x - x₁)

8. Parallel Lines

Parallel lines are lines that travel in the same direction and never meet, even if they are extended indefinitely.

On a coordinate plane, two different non-vertical lines are parallel when they have the same slope.

m₁ = m₂
Example

Are these lines parallel?

y = 3x + 2
y = 3x - 5
First line slope = 3
Second line slope = 3

Since their slopes are equal, the lines are parallel.

9. Perpendicular Lines

Perpendicular lines meet at a right angle, which means the angle between them is 90°.

For two non-vertical lines to be perpendicular, their slopes are negative reciprocals of each other.

m₁ × m₂ = -1

A negative reciprocal means two things happen: the sign changes and the fraction is flipped.

Example

A line has slope 2. Find the slope of a perpendicular line.

Write 2 as a fraction:
2 = 2/1

Flip the fraction:
1/2

Change the sign:
-1/2

10. Finding the Equation of a Line

Sometimes you are given information about a line and asked to find its equation.

The most common information provided is a point on the line and its slope, or two points on the line.

When the Slope and One Point Are Known

Use:

y - y₁ = m(x - x₁)
Worked Example

Find the equation of the line with slope 3 passing through (2, 5).

y - 5 = 3(x - 2)

Expand:
y - 5 = 3x - 6

Add 5:
y = 3x - 1

When Two Points Are Known

First calculate the slope using the two points. Then use one of the points with the point-slope formula.

11. x- and y-Intercepts

An intercept is a point where a graph crosses one of the coordinate axes.

y-Intercept

To find the y-intercept, set x equal to zero.

x = 0

x-Intercept

To find the x-intercept, set y equal to zero.

y = 0
Worked Example

Find the intercepts of:

y = 2x + 6
y-intercept:
Set x = 0.
y = 2(0) + 6
y = 6
y-intercept = (0, 6)

x-intercept:
Set y = 0.
0 = 2x + 6
-6 = 2x
x = -3
x-intercept = (-3, 0)

12. Circles on the Coordinate Plane

Coordinate geometry can also be used to describe circles.

The standard equation of a circle is:

(x - h)² + (y - k)² = r²

In this equation, (h, k) is the centre of the circle and r is its radius.

Understanding the Equation

The equation tells us that every point on the circle is exactly the same distance from the centre.

Example

Identify the centre and radius of:

(x - 3)² + (y + 2)² = 25
Compare with:
(x - h)² + (y - k)² = r²

h = 3
k = -2
r² = 25
r = 5

Centre = (3, -2)
Radius = 5

13. Applications of Coordinate Geometry

Coordinate geometry is not just about drawing points on graphs. It gives us mathematical tools for describing positions, shapes and relationships.

Maps and Navigation

Coordinates can be used to represent locations on maps. Distances and directions can then be calculated mathematically.

Architecture and Construction

Engineers and architects can use coordinate systems to describe exact positions and dimensions of structures.

Computer Graphics

Computers use coordinates to position objects on screens. Moving an object to the right, left, up or down can all be represented using changes in coordinates.

Physics

Coordinates are also used to describe the position and movement of objects.
