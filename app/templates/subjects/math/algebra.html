Algebraic Expressions & Terms

What Is Algebra?

Algebra is a branch of Mathematics that uses letters and symbols to represent numbers and quantities.

Instead of always working with known numbers, algebra allows us to work with unknown values.

Example:

If you do not know a number, you can represent it with x.

If you add 5 to that number, the expression becomes:

x + 5

Variables

A variable is a letter or symbol used to represent an unknown or changing quantity.

Common variables include:

x, y, a, b, n and t.

Example:

If x represents the number of books a student has, then:

x + 3

represents three more books than the student originally had.

Constants

A constant is a value that does not change.

Example:

In:

3x + 7

7 is the constant.

Coefficients

A coefficient is the number multiplying a variable.

Example:

In:

5x

5 is the coefficient of x.

Terms

Terms are parts of an algebraic expression separated by addition or subtraction signs.

Example:

Consider:

4x + 7y - 3

The terms are:

  • 4x
  • 7y
  • -3

Like Terms

Like terms contain the same variables raised to the same powers.

Example:

3x and 7x are like terms.

4y² and 9y² are like terms.

But x and x² are not like terms.

Collecting Like Terms

Like terms can be combined by adding or subtracting their coefficients.

Example:

3x + 5x

Add the coefficients:

8x
Example:

7x + 3y - 2x + 5y

Collect the x terms:

7x - 2x = 5x

Collect the y terms:

3y + 5y = 8y

Therefore:

5x + 8y

Expanding Brackets

To expand a bracket, multiply the term outside the bracket by every term inside it.

Example:

3(x + 4)

Multiply 3 by both terms:

3 × x = 3x

3 × 4 = 12

3x + 12

Factorising

Factorising is the reverse of expanding brackets.

Example:

6x + 12

The highest common factor is 6.

6(x + 2)

Linear Equations & Inequalities

What Is an Equation?

An equation states that two mathematical expressions are equal.

Left side = Right side
Example:

x + 5 = 12

The equation tells us that x plus 5 equals 12.

Solving Simple Equations

The goal is to find the value of the unknown variable.

Example:

x + 7 = 15

Subtract 7 from both sides:

x = 15 - 7

x = 8

Equations Involving Multiplication

Example:

4x = 20

Divide both sides by 4:

x = 5

Equations with Brackets

Example:

3(x + 2) = 15

Divide by 3:

x + 2 = 5

Subtract 2:

x = 3

Equations with Fractions

Example:

x/3 = 5

Multiply both sides by 3:

x = 15

Changing the Subject of a Formula

Changing the subject means rearranging a formula so that a different variable appears alone.

Example:

Make x the subject:

y = x + 5

Subtract 5 from both sides:

x = y - 5

Inequalities

Inequalities compare quantities that are not necessarily equal.

Symbol Meaning
> Greater than
< Less than
≥ Greater than or equal to
≤ Less than or equal to
Example:

x + 3 > 7

Subtract 3:

x > 4
Important:

When multiplying or dividing an inequality by a negative number, the inequality sign reverses.

Formulae & Algebraic Manipulation

Substitution

Substitution means replacing a variable with a known value.

Example:

If:

y = 3x + 2

and x = 4:

y = 3(4) + 2

y = 12 + 2

y = 14

Algebraic Formulae

A formula is a mathematical rule showing the relationship between different quantities.

Example:

Area of a rectangle:

A = lw

where l is length and w is width.

Changing the Subject

Example:

Given:

A = lw

Make l the subject.

Divide both sides by w:

l = A/w

Indices in Algebra

Indices describe repeated multiplication.

x² = x × x

Important laws include:

xᵃ × xᵇ = xᵃ⁺ᵇ

xᵃ ÷ xᵇ = xᵃ⁻ᵇ

(xᵃ)ᵇ = xᵃᵇ

Algebraic Fractions

Algebraic fractions contain variables in the numerator or denominator.

Example:

Simplify:

6x / 9x

Cancel common factors:

2/3

Expanding Double Brackets

Example:

(x + 2)(x + 3)

Multiply each term:

x × x = x²

x × 3 = 3x

2 × x = 2x

2 × 3 = 6

Therefore:

x² + 5x + 6

Difference of Two Squares

a² - b² = (a-b)(a+b)
Example:

x² - 25

Since 25 = 5²:

(x - 5)(x + 5)

Simultaneous & Quadratic Equations

Simultaneous Equations

Simultaneous equations are two or more equations containing the same unknown variables.

Example:

x + y = 10

x - y = 2

Add the equations:

2x = 12

x = 6

Substitute into x + y = 10:

6 + y = 10

y = 4

Methods of Solving Simultaneous Equations

  • Substitution
  • Elimination
  • Graphical method

Quadratic Expressions

A quadratic expression contains a variable raised to the power of 2.

Examples:

x² + 5x + 6

2x² - 3x + 1

Factorising Quadratics

Example:

Factorise:

x² + 5x + 6

Find two numbers that multiply to 6 and add to 5.

2 and 3.

(x + 2)(x + 3)

Solving Quadratic Equations by Factorisation

Example:

Solve:

x² + 5x + 6 = 0

Factorise:

(x + 2)(x + 3) = 0

Therefore:

x + 2 = 0

or

x + 3 = 0

x = -2 or x = -3

Quadratic Formula

When factorisation is difficult, the quadratic formula can be used.

x = (-b ± √(b² - 4ac)) / 2a

For an equation in the form:

ax² + bx + c = 0

The Discriminant

The discriminant is:

b² - 4ac

It helps determine the number of real solutions of a quadratic equation.

Discriminant Solutions
> 0 Two distinct real solutions
= 0 One repeated real solution
< 0 No real solutions

Sequences, Functions & Graphs

Sequences

A sequence is an ordered list of numbers following a particular pattern.

Example:

2, 4, 6, 8, 10, ...

The pattern is adding 2 each time.

Arithmetic Sequences

An arithmetic sequence has a constant difference between consecutive terms.

aₙ = a₁ + (n - 1)d

where:

  • aₙ = nth term
  • a₁ = first term
  • n = term number
  • d = common difference
Example:

Find the 10th term of:

3, 6, 9, 12, ...

First term = 3

Common difference = 3

Therefore:

a₁₀ = 3 + (10 - 1)(3)

a₁₀ = 30

Functions

A function is a rule that connects an input to an output.

Example:

f(x) = 2x + 1

If x = 3:

f(3) = 2(3) + 1

f(3) = 7

Coordinates

A point on a coordinate plane is written as:

(x, y)

The first number represents the horizontal position. The second represents the vertical position.

Example:

The point (3, 5) means:

Move 3 units along the x-axis and 5 units upward.

Linear Graphs

A straight-line graph can be written in the form:

y = mx + c

where m represents the gradient and c represents the y-intercept.

Gradient

The gradient measures how steep a line is.

m = (y₂ - y₁) / (x₂ - x₁)
Example:

For points (1,2) and (3,6):

m = (6 - 2)/(3 - 1)

m = 4/2

m = 2

Quadratic Graphs

A quadratic function produces a curved graph called a parabola.

y = ax² + bx + c

The value of a determines whether the parabola opens upward or downward.
